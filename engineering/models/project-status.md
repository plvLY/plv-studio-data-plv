# 项目状态模型

项目状态模型用有限的状态描述项目整体所处的位置，避免用模糊的描述判断进度。

## 状态定义

| 状态 | 含义 |
| --- | --- |
| 规划中 | 目标与方案尚未确定，未进入实现 |
| 开发中 | 正在实现或验证，尚未正式交付 |
| 已上线 | 已交付并处于可访问状态 |
| 已归档 | 不再维护，仅保留记录 |

## 状态与阶段的关系

状态回答「项目整体怎么样」，阶段回答「项目走到哪一步」。

- 一个项目可能长期处于「开发中」，跨越多个阶段
- 「已上线」不等于流程结束，运行阶段仍可能继续
- 「已归档」表示停止维护，不代表内容被删除

## 使用原则

- 状态必须能从项目记录中得到解释
- 状态变更应伴随时间点与原因
- 不使用「差不多完成」「基本可用」这类无法验证的描述
