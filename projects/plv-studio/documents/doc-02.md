# 需求分析

## 页面需求

| 页面 | 核心内容 |
|------|---------|
| 首页 | Hero、Live Stats、精选作品、正在开发、能力与证据、发布日志、通用流程 |
| 作品列表 | 封面、状态、技术标签、进度摘要、最近更新 |
| 作品详情 | STAR、架构图、概览、进度时间线、文档、验收与上线 |
| 设计文档 | Markdown、构建期 Mermaid、代码高亮与复制、目录、上下篇 |
| About | 简介、技术主线、能力证据、八阶段工作方式、公开入口 |
| 404 | 友好提示、返回首页、作品入口 |

## 八阶段

产品规划 → 需求分析 → 产品设计 → 系统架构与技术设计 → 开发实施 → 测试与质量保障 → 部署与发布 → 运行与持续迭代。

阶段只有三种状态：`planned`、`in-progress`、`completed`；状态必须连续。

## 关键约束

- 内容全部在构建期读取，首页"正在开发"必须存在于静态 HTML。
- 允许多个作品同时开发，首页并列展示，不设单一主推。
- 精选作品 1 ~ 3 个，可指定。
- 内容更新只改数据仓库，不修改框架代码。

## 非功能

- 纯静态、无后端；`check` 与 `build` 必须通过。
- 移动端 LCP ≤ 2.5s、CLS ≤ 0.1、INP ≤ 200ms。
- WCAG 2.1 AA；键盘可完成主要操作。
- 每个页面有独立 title、description、canonical 与 OG 信息。
