# PLV Site Monitor 产品需求说明

**摘要**：定义产品定位、目标场景、功能范围、指标口径、非目标及已确认的产品约束。

## 1. 产品定位

PLV Site Monitor 是面向个人开发者的自用网站访问统计与站点管理系统。采用单一超级管理员模式，由管理员集中管理多个被采集站点，查看访问趋势、页面、来源、设备及地域等统计信息。

## 2. 目标与使用场景

- 集中查看个人网站、作品集和独立站点的访问表现。
- 通过轻量 Tracker 接入被采集站点。
- 无需单独维护常驻统计服务器，优先使用 Netlify Serverless 与 PostgreSQL 承载服务。
- 以可核验的数据采集链路和 Dashboard 统计结果作为核心交付。

## 3. 用户与权限边界

- 系统仅设置一个超级管理员账户。
- 超级管理员登录后管理全部站点。
- 当前不提供普通用户注册、多用户组织、租户体系或复杂 RBAC。
- Dashboard 管理 API 必须在服务端验证管理员身份和会话；前端路由守卫不能替代服务端认证。
- Tracker 的公开采集入口不要求 Dashboard 管理员登录，但必须执行独立的服务端校验。

## 4. 功能范围

### 4.1 站点管理

- 创建、查看、编辑和删除站点。
- 配置站点域名、时区及启停状态。
- 创建成功后使用 API 返回的真实 Site ID 生成 Tracker 接入代码。

### 4.2 访问采集

- 当前 MVP 核心事件为 `page_view`。
- Tracker 将事件发送至公开 Collect API。
- 服务端验证站点状态、域名/访问范围、事件数据及限流。
- 事件持久化至 PostgreSQL，并通过站点与事件标识的唯一性约束实现幂等去重。

### 4.3 Analytics

| 页面/维度 | 目标能力 |
| :--- | :--- |
| Overview | 核心访问指标概览 |
| Trends | PV / UV 时间趋势 |
| Pages | 页面维度统计 |
| Sources | 来源维度统计 |
| Devices | 设备维度统计 |
| Locations | 地域维度统计 |

时间范围包含 `today`、`yesterday`、`7d`、`30d`、`custom`。日期边界、时区与聚合细节以当前 Service、Validator 和测试为准。

### 4.4 管理设置

- 单一超级管理员登录、会话恢复与退出。
- 系统级 Settings 单例配置。
- 每站点采集限流配置。
- 隐私与数据保留相关设置。

## 5. 指标定义边界

- PV：统计范围内符合条件的页面访问事件数。
- UV：统计范围内 distinct `visitor_id` 数。
- Sessions：统计范围内 distinct `session_id` 数。
- Bounce Rate：以当前 Analytics 聚合实现为准；在未逐项核对实现与测试前，不在本需求文档中补写公式。

## 6. 非目标

当前版本不包含网站 uptime 探测、在线率 SLA、告警、普通用户注册、多租户、复杂权限编排、热力图、点击轨迹、会话录制、转化漏斗、自定义事件平台、A/B 测试及计费订阅。

## 7. 已确认产品约束

1. 个人自用，单一超级管理员。
2. 管理接口服务端认证；公开采集接口独立保护。
3. 服务端负责站点有效性、事件合法性、限流及隐私规则。
4. 计划、实现、测试通过、生产验证和用户正式验收必须分别记录。
5. 不得将未验收或仅规划的功能写成已交付能力。
