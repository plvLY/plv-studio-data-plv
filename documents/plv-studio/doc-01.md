# 产品规划

## 品牌

- 个人品牌：吖飘，独立开发者。
- 工作室品牌：PLV Studio，个人研发工作室。
- 品牌标语：Build. Document. Deliver.

## 产品定位

PLV Studio 是项目全生命周期展示平台，核心是**作品 + 过程 + 进度**。

它不展示静态的"完成态"，而是展示项目从需求、设计、架构、开发到发布的真实过程；首页需要让访客一眼看到"正在做什么"。

## 架构原则

1. 框架与数据物理分离：框架仓库唯一，数据仓库按主体独立。
2. 数据更新经 Deploy Hook 自动触发框架重建，构建期读取数据。
3. 纯静态路线，不引入数据库与后端服务。
4. 八阶段模型统一，所有作品共用同一套状态与展示组件。

## MVP 范围

- 首页 8 个区块：Header、Hero、精选作品、正在开发、能力与证据、发布日志、通用开发流程、Footer。
- 作品列表、作品详情、设计文档、About、404。
- 数据契约、构建期校验、设计令牌、浅色/暗色主题、SEO 基础。
- 不包含登录、后台、CMS、评论、Serverless Function。
